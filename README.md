# Основы кинематики и теория механизмов

Интерактивный учебник на русском языке.

**Основной курс (темы 1–12):** материальная точка, системы счисления, sin/cos, вращательное движение, звенья, кинематические пары и цепи, кривошипно-ползунный механизм, тест из 10 вопросов.

**Углублённый курс (темы 13–19):** скорость и ускорение ползуна, план скоростей, степени свободы (формула Чебышёва), классификация пар, четырёхзвенник и условие Грасгофа, мёртвые точки и угол давления, шпаргалка формул и тест из 12 вопросов.

Один файл `index.html` (HTML, CSS, JavaScript, SVG), без сборки. Откройте его в браузере двойным щелчком.

Шрифты подгружаются с Google Fonts; без интернета страница работает на системных шрифтах.
